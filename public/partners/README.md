# Partner logos

Default logos shipped with the repository, so they are present on a fresh
deployment (the `/app/uploads` volume starts empty).

- `bangladesh-govt-emblem.png` — the emblem of the Government of the People's
  Republic of Bangladesh, downloaded from the official sites of the Bangladesh
  Technical Education Board (bteb.gov.bd) and the Ministry of Education
  (moedu.gov.bd), which both use it as their site logo. Both sites serve the
  identical file.

Staff can replace any of these from Admin → অনুমোদন ও সহযোগী → লোগো; an
uploaded logo takes precedence over the file here.

See HANDOVER.md for the note about confirming permission to display it.
